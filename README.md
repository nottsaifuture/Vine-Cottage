# Vine Cottage — Interactive 3D Presentation

Built website for the interactive Three.js presentation of Vine Cottage, Petworth Road, Witley GU8 5LS.

Live site: https://nottsaifuture.github.io/Vine-Cottage/

## Controls

- Drag to rotate and scroll or pinch to zoom.
- Select cellar, ground floor, first floor, roof-off, or dollhouse views.
- Use the viewpoint menu for room-focused views.
- Start Walkthrough for first-person movement and interactive doors.
- Enable labels, dimensions, furniture, the minimap, or evening lighting as needed.
